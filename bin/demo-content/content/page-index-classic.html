Dinamiko PDF demo for a classic theme (Twenty Twenty-One). Open any item and click “Download PDF”, or use the direct links below.

This demo has only the content a classic site would have: core blocks, shortcodes and classic-editor HTML. Block theme features (theme patterns, full-page patterns, synced patterns and block templates) are in the block theme demo instead, which you build with npm run demo:seed.

What to expect with a classic theme

  • The PDF contains only the post content. The theme's site header, menu, widgets and footer are left out.
  • The content is styled by the theme's stylesheet through the classic wrappers (.site-main, .entry-header .entry-title, .entry-content), so headings, links, quotes and tables follow Twenty Twenty-One's look.
  • Posts built with core blocks keep their block styles (columns, galleries, buttons, tables).
  • The classic-editor post (no block markup) exports the same way as the block posts.
  • All text uses the bundled Noto Sans font, and the page background is white.
  • Blocks and elements with the dinamiko-pdf-page-break class start a new page.
  • Videos, audio and iframes become links to the original.
  • The header and footer set under Settings → Dinamiko PDF appear on every PDF page.

Rebuild with npm run demo:seed:classic, switch to the block theme demo with npm run demo:seed, remove with npm run demo:clean.
