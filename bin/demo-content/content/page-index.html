What to look for

  • The PDF has only the content: no header, footer or sidebar, whichever template the page uses.
  • Theme styles (colours, spacing, font sizes) match the page; the font is replaced by Noto Sans.
  • Blocks with the cpdf-page-break class start a new page.
  • Videos and iframes become links.
  • Theme patterns and the custom template are specific to Twenty Twenty-Five. With a classic theme (Twenty Twenty-One) those pages render without them.

Rebuild with npm run demo:seed, remove with npm run demo:clean.
