What to expect with a block theme

This demo activates Twenty Twenty-Five.

  • The PDF contains only the post content. Whichever template the page uses (including “Page No Title” and the custom landing template), the template parts such as the header, navigation and footer are left out.
  • Colours, spacing and font sizes come from theme.json global styles and the block styles, so columns, galleries, cover blocks and patterns look as they do on the page.
  • The title uses the theme's post title style (.wp-block-post-title).

With every theme

  • All text uses the bundled Noto Sans font, and the page background is white.
  • Blocks with the cpdf-page-break class start a new page.
  • Videos, audio and iframes become links to the original.
  • The header and footer set under Settings → Content PDF appear on every PDF page.

Rebuild with npm run demo:seed (block) or npm run demo:seed:classic (classic), remove with npm run demo:clean.
